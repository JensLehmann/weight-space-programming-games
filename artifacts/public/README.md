# Writer artifacts on the public ARC-AGI-3 games

The final artifacts of all feedback-guided writer sessions on the 25 public games
(`official.<id>`): W2 (weights of the fixed actor), P2 (Python player) and FA W2 (free-architecture
network), 4 writers x 3 runs each, together with the prompts of the three arms (without the game
source, see "Prompts").

| Path | Contents |
|---|---|
| `<game>/<writer>/w2_r<k>.py` | W2, run `k`: the writer's program; its `build()` returns all 57,289 weights of the fixed actor |
| `<game>/<writer>/p2_r<k>.py` | P2, run `k`: the writer's Python player (`act()`) |
| `<game>/<writer>/fa_w2_r<k>.py` | FA W2, run `k`: the writer's program; its `build()` returns a network in the free-architecture graph language and all its weights |
| `<game>/prompts/{w,p,fa}.md` | The prompt of the W, P and FA arm: the first and only message of round 0, identical for every writer and run (the W and P prompts are also those of W1 and P1), verbatim except that the official game source is replaced by a placeholder (see "Prompts") |
| `<game>/prompts/hashes.json` | SHA-256 of the full prompts (as frozen before any writer call in `manifests/rev2/freeze_public.json` and `freeze_fa.json`; for `official.ka59` in `freeze_public_ka59.json`), of the released prompts, of the removed game source and of the whole game section |
| `index.csv` | One row per session (900), including the 3 sessions that delivered no artifact |

Each program is the writer's source of the round the session delivered (`final_round`: the valid round
that solved the most support episodes, the latest on ties). Writer labels are those of `data/sessions.csv`.
The feedback messages of later rounds are not included; they are generated from the support-set
results by `wsp/prompts.py::feedback_message` (W, P) and `wsp/prompts_fa.py::feedback_message_fa` (FA).

**The programs are model outputs, released unmodified**: every program is byte-identical to
the writer's output. Run them only through the harness, which audits and isolates writer code
(`wsp/sandbox.py`).

The programs restate game mechanics in the writers' own code.

## Prompts

The official game source is not redistributed. In each prompt, the fenced official game source of the game
section (the redacted `<id>.py`, with the held-out levels withheld) is replaced by one line:

```
[GAME SOURCE NOT INCLUDED: the redacted (mechanics-only) source of the official game file `<id>.py` of official.<id>, generated by scripts/build_sections_public.py (wsp.redact_public.public_section); restore it with scripts/rebuild_public_prompts.py; sha256 <hash>]
```

Everything else is verbatim: the task and interface text, the section's description of the game and
its `arcengine` excerpts (MIT License), the episode rules and the support observations. The quoted
code keeps its original terms.

`scripts/rebuild_public_prompts.py` restores the full prompts from the official game files, given with
`--official-root DIR`, a directory with `<id>/<version>/<id>.py` as published (e.g.
`$WSP_OFFICIAL_ROOT`, see "Re-scoring a released public artifact" in the main README), or read from the
game package's cache. It checks each game file against
`env.source_sha256` in `manifests/rev2/queries_official.<id>.json`. It then regenerates the redacted
source with the released redaction configs (`wsp/redact_public.py`, `wsp/redact_public_configs.py`),
inserts it, and checks the game section and the prompt against the hashes frozen before any writer
call. With `--out DIR` it writes the full prompts. All 75 rebuilt prompts match their frozen hashes.

## `index.csv`

| Column | Meaning |
|---|---|
| `game`, `writer`, `condition` (`w2`, `p2`, `fa_w2`), `run` | Session |
| `final_round` | Round of the delivered artifact (0-based); empty if none |
| `delivered` | 1 if the session delivered an artifact. 0 for writer errors or refusals and for FA sessions with no valid network in any round; these rows have no file |
| `file`, `sha256` | Path relative to this directory and SHA-256 of the file |
| `s_start`, `q_off` | Solve rate on S-start (support starts) and Q-off (perturbed starts on support levels) |
| `q_lvl_level_balanced` | Mean over held-out levels of the per-level success on Q-lvl (the headline metric; 0 if not delivered) |
| `fa_params`, `fa_macs_per_step`, `fa_node_evals_per_step` | FA only: parameter count, multiply-accumulates and node evaluations per step of the delivered network, as counted by the harness |

The values are those of the matching rows of `data/sessions.csv`.

## Rebuilding and evaluating an artifact

```python
import torch
torch.backends.cuda.matmul.allow_tf32 = False      # exact FP32 (see the main README)
torch.backends.cudnn.allow_tf32 = False
from collections import defaultdict
from pathlib import Path
from wsp.queries import load_sets
from wsp.session import evaluate, materialize

code = Path("artifacts/public/official.ls20/astra-6/w2_r0.py").read_text()
art = materialize("weights", code)         # "python" for p2_*.py, "freearch" for fa_w2_*.py
assert art.error is None, art.error
sets = load_sets("official.ls20", rev=2)   # frozen query sets: manifests/rev2/queries_official.ls20.json
res = evaluate(art, sets["Q-lvl"])         # also "S-start", "Q-off"; without CUDA: device="cpu", batch=1 (see Numerics)
per = defaultdict(list)
for spec, r in zip(sets["Q-lvl"], res):
    per[spec.level].append(r.success)
print(sum(sum(v) / len(v) for v in per.values()) / len(per))    # q_lvl_level_balanced
```

`wsp.session.materialize` runs the program's `build()` (W2, FA) in the sandbox and validates the
result. `art.params` holds the float32 weights. For FA, `art.graph` holds the validated graph and
`art.audit["count"]` the budgets. This step needs neither the games nor a GPU, and it is
deterministic: for every W2 and FA program, the rebuilt weights, FA graphs and budgets are identical to those
saved during the study. `wsp.actor.save_npz(art.params, path)` (W2) and
`wsp.freearch.save_artifact(art, out_dir, k)` (FA) save them in the study's format. A P2 player has no
build step: `evaluate` runs its `act()` in the sandbox.

**Evaluation** needs the engine of the official games, `arcengine` 0.9.3 (`pip install -e ".[public]"`),
the official game files in `$WSP_OFFICIAL_ROOT` and the released level-entry routes
(`manifests/public/`), but not the game-collection package; see "Re-scoring a released public artifact"
in the main README, which also gives the command that does all of the above for released files
(`scripts/eval_artifacts.py <file or directory> --out DIR`).

**Numerics.** The solve rates in `index.csv` come from `scripts/eval_artifacts.py`: exact FP32 on
CUDA, batches of 64 (its defaults). Written networks have high gains. Another backend's rounding differences can
therefore flip their decisions (exactly tied logits occur), and in some FA networks they grow to
non-finite values. In the FA network below, batched CPU execution first differs by about 1e-6, in a
convolution. Without CUDA, evaluate W2 and FA artifacts on CPU, one episode at a time:
`evaluate(art, specs, device="cpu", batch=1)` (`--device cpu --batch 1` of `scripts/eval_artifacts.py`). The default device is MPS where available, and MPS
matches the reference only to about 3e-3.

We checked two artifacts:

| Artifact | Sets | CPU, batch 1 | CPU, batch 64 |
|---|---|---|---|
| `official.ls20/astra-6/w2_r0.py` | S-start, Q-off, Q-lvl | every episode as in the study | 16 of 24 Q-off episodes change |
| `official.cd82/terra-6.1/fa_w2_r0.py` | S-start, Q-lvl | every episode as in the study | 40 of 63 Q-lvl episodes change; level-balanced Q-lvl 0.33 instead of 0.97 |

For the W2 actor, single-episode play also matches the float32 NumPy reference
(`wsp.actor.reference_step`) at every step of the 16 changed episodes. P2 players are not affected.
